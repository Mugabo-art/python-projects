# 🔑 Hash Table

A simple implementation of a **Hash Table** data structure in Python.

## Features

-   Custom hash function
-   Add, remove and lookup key-value pairs
-   Collision handling

## Project Structure

``` text
hash-table/
├── main.py
└── README.md
```

## Example

``` python
from main import HashTable

table=HashTable()
table.add('golf','sport')
print(table.lookup('golf'))
```
