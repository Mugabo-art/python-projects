# User Configuration Manager

A simple Python-based manager for user settings, allowing users to add, update, delete, and view their configurations.

## Features
- **Add Settings:** Add new configuration keys and values.
- **Update Settings:** Easily modify existing configuration values.
- **Delete Settings:** Remove unwanted configuration keys.
- **View Settings:** Display current settings in a clean, readable format.
